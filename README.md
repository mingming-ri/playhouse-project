# playhouse-project


first cad project! made using onshape. done with help from and for hackclub's playhouse ysws!

rip sorry i don't have much because i was learning for the first time along the way.


i made a star wall decoration, a window, and a photo frame for the walls.

also made a bed and side table, as well as a ceiling lamp.

for the floor, i made a tiled floor, a plank floor, a moon/sun rug, and a star rug
